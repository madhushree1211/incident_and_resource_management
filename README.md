# Project Documentation

## Installation
To install the project, please follow the steps below:
1. Clone the repository:
   ```
   git clone https://github.com/madhushree1211/incident_and_resource_management.git
   ```
2. Navigate to the project directory:
   ```
   cd incident_and_resource_management
   ```
3. Install the required dependencies:
   ```
   npm install
   ```

## Setup
Before running the project, ensure that you have the following configurations:
- Update the configuration files located in `/config` directory according to your environment.

## Running Instructions
To start the project, run the following command:
```bash
npm start
``` 

Visit `http://localhost:3000` in your browser to access the application.
